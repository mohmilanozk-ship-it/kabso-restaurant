# النجم ستور — متجر شحن الألعاب والخدمات الرقمية

نسخة أولية عملية مبنية باستخدام Next.js 15 وTypeScript وPrisma وSQLite. الواجهة عربية RTL ومتجاوبة، مع حسابات مستخدمين وجلسات آمنة عبر HttpOnly cookies، ولوحة مدير وطلبات يدوية.

## المتطلبات
- Node.js 20.9 أو أحدث
- npm

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env`.
2. غيّر `JWT_SECRET` إلى قيمة عشوائية طويلة، وغيّر `STORE_ADMIN_EMAIL` و`STORE_ADMIN_PASSWORD` قبل التشغيل.
3. ثبّت الحزم: `npm install`
4. أنشئ قاعدة البيانات: `npm run db:push`
5. أضف المدير والبيانات التجريبية: `npm run db:seed`
6. شغّل التطبيق: `npm run dev`
7. افتح `http://localhost:3000`.

بيانات المدير تُقرأ من `.env` عند تنفيذ seed. يجب تعيين كلمة مرور فريدة بطول 12 حرفاً على الأقل في `.env` قبل تشغيل seed. البريد الإداري المعين لا يعني أنه تم التحقق من ملكيته.

## الصفحات
- `/` المتجر والمنتجات وإنشاء الطلب
- `/login` تسجيل الدخول
- `/register` تسجيل العملاء
- `/orders` تتبع الطلب برقم الطلب
- `/admin` لوحة الإدارة (للمدير فقط)

## واجهات API الأساسية
- `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`
- `GET /api/products`, `GET /api/categories`
- `POST /api/orders`, `GET /api/orders/:number`
- `GET/PATCH /api/admin/orders` (مدير)
- `POST/PATCH /api/admin/products` (مدير)
- `POST/PATCH /api/admin/categories` (مدير)
- `GET/POST /api/admin/payment-methods`

## قاعدة البيانات
SQLite للتشغيل السريع. المخطط يحتوي Users وCategories وProducts وProductVariants وOrders وOrderItems وPayments وPaymentMethods وCoupons وReviews وNotifications وStoreSettings وAdminLogs.

## ملاحظات قبل النشر
- المشروع يستخدم SQLite محلياً للتجربة. للنشر متعدد النسخ/المستخدمين يوصى بتحويل Prisma datasource إلى PostgreSQL وتعيين `DATABASE_URL`، ثم تنفيذ migration مناسب.
- `public/uploads` تخزين محلي مناسب للتطوير فقط؛ استخدم S3 أو Cloudinary أو مزود تخزين خاص في الإنتاج.
- إرسال البريد غير مفعل بعد؛ إعدادات SMTP موجودة في `.env.example` وتحتاج ربط مزود بريد وتنفيذ الإرسال والتحقق من البريد واستعادة كلمة المرور.
- إثبات الدفع لا يُعتمد آلياً؛ اعتماد الدفع وتنفيذ الشحن يجب أن يتم يدوياً من المدير. لا توجد حتى الآن شاشة إدارة كاملة لطرق الدفع أو مراجعة صورة الإثبات ضمن لوحة المدير. لا توجد حتى الآن شاشة إدارة كاملة لطرق الدفع أو مراجعة صورة الإثبات ضمن لوحة المدير. لا يوجد ربط API شحن خارجي.
- يلزم إضافة بوابة دفع رسمية، رفع إثبات الدفع من العميل، حماية معدل الطلبات، CSRF/Origin checks، مراجعة الخصوصية والشروط، اختبارات آلية، ومراقبة/نسخ احتياطي قبل الاستخدام التجاري العام.
- لا تستخدم بيانات أو مفاتيح حقيقية في مستودع Git. احفظ الأسرار في إعدادات الاستضافة.

## الأمان الحالي وحدوده
- كلمات المرور تُخزّن باستخدام bcrypt مع cost 12.
- الجلسة JWT موقعة وتُحفظ في HttpOnly/SameSite cookie.
- مسارات الإدارة تتحقق من دور ADMIN على الخادم.
- التحقق من بيانات التسجيل والطلب والمنتج عبر Zod.
- رفع صور المنتجات مقيد بالمدير ونوع الملف والحجم؛ ورفع إثبات الدفع يسمح بصور محدودة الحجم، ويلزم إضافة rate limiting وتخزين خارجي قبل الإنتاج.
- هذه نسخة MVP قيد التطوير وليست مراجعة أمنية أو شهادة جاهزية إنتاجية.
