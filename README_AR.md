# النجم ستور — نسخة تأسيسية Flutter

هذه ملفات مصدر أولية لتطبيق Android وليست APK/AAB جاهزاً للنشر أو نظاماً مكتملاً.

## الموجود حالياً
- واجهة عربية RTL وهوية سوداء/ذهبية.
- تسجيل وإنشاء حساب عبر Firebase Authentication.
- عرض المنتجات من Firestore.
- إنشاء طلبات مرتبطة بحساب العميل وعرض طلباته.
- رفع إثبات الدفع إلى Firebase Storage للمراجعة اليدوية.
- قواعد أمان مبدئية في مجلد firebase.

## الخطوة التالية لإكمال الربط
1. أنشئ مشروع Firebase من حسابك.
2. فعّل Email/Password في Authentication.
3. أنشئ Firestore وStorage.
4. في بيئة Flutter، شغّل `flutter pub get` ثم ثبّت FlutterFire CLI وشغّل `flutterfire configure`.
5. انشر قواعد الأمان من ملفات `firebase/`.
6. أضف منتجات إلى مجموعة `products`، وكل مستند يحتاج: `name`, `description`, `price`, `currency`, `active`.
7. اختبر التسجيل والطلب ورفع الإثبات قبل الاستخدام الحقيقي.

## حماية المدير
لا يمكن للمستخدم ترقية نفسه إلى مدير. لوحة الإدارة غير مضافة في هذه النسخة الأولية بعد؛ يجب إنشاءها بعد ضبط Firebase Custom Claims (`admin: true`) من بيئة موثوقة باستخدام Firebase Admin SDK. لا تضع أسراراً أو كلمات مرور في التطبيق.

## حدود مهمة
- لا يوجد دفع آلي؛ مراجعة إثبات الدفع يدوية.
- لا توجد لوحة إدارة مكتملة، باقات متعددة، إشعارات، كوبونات، أو تقارير بعد.
- لم يتم ربطه بمشروع Firebase حقيقي أو اختباره على جهاز.
- Firebase يقدم حدوداً مجانية لبعض الاستخدامات، لكن التخزين وبعض الميزات والحدود تتغير حسب الخطة والمنطقة؛ راجع الأسعار الرسمية قبل الإطلاق.
- قبل Google Play يلزم إعداد سياسة خصوصية وإفصاحات البيانات واختبارات المتجر ومتطلبات حساب المطور الحالية.

## البناء
بعد إعداد Flutter وFirebase:
`flutter build appbundle --release`
والملف الناتج يكون عادة في `build/app/outputs/bundle/release/app-release.aab`.
